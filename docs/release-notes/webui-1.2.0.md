### ⚠️ Upgrade notes

- **Requires firmware 2.3.1 or newer and WebUI API 1.** Install the image under **System → WebUI**. Firmware updates use the separate **System → Firmware** page.

### ✨ Improvements

- **WebUI 1.2.0 is available on the stable channel.** The standalone SPIFFS image provides the New Design interface and can be installed independently of the firmware.
- **The WebUI verifies the new image before activating it.** The gateway checks the partition image and compatibility manifest.
