# Release notes

Use the [IDM Heatpump release layout](https://github.com/Xerolux/idm-heatpump-hass/releases)
for firmware and WebUI. Write the version and date, any upgrade or compatibility
notes, grouped user-facing improvements and fixes, and a link comparing the
previous release with the new tag. Include verification details where they clarify
what was tested.

Add the notes before starting the release workflow:

- Firmware: `docs/release-notes/firmware-<version>.md`.
- WebUI: `docs/release-notes/webui-<version>.md`.

Keep firmware and WebUI version histories independent. Edit upcoming notes on the
release branch and preserve older published entries.
