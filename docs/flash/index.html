HB-RF-ETH-ng Web-Flasher

Firmware direkt im Browser über das USB-Kabel flashen – ohne Python, ohne Installation.

← Zur Übersichtsseite

1Vorbereitung

  • Datenkabel verwenden – viele USB-Kabel sind reine Ladekabel ohne Datenleitungen.
  • Funkmodul abziehen (RPI-RF-MOD / HM-MOD-RPI-PCB) – es stört die serielle Verbindung beim Flashen.
  • Platine nur über USB versorgen; PoE/Ethernet während des Flashens abziehen.
  • Browser: Chrome oder Edge am PC/Mac (Web Serial). Firefox und Safari unterstützen das nicht.
  • Windows: Falls der Port nicht erscheint, einmalig den CH340-Treiber von wch-ic.com installieren.

2Firmware wählen

Migration von der Original-Firmware (1.3.x): „Komplettinstallation" wählen – sie ersetzt die alte Firmware in einem Durchgang. Alternativ funktioniert weiterhin das Migrationsskript im Repository.
